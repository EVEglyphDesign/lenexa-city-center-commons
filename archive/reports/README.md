# archive/reports/

Dated output of the propose-only sweep, one directory per day: `YYYY-MM-DD/`.

Everything in here is a **proposal**. Nothing in here is on the map.
A proposal becomes a note only when a human moves it into `notes/` by pull request.

Kept even when rejected — the record of what was considered and declined is part of the
durable asset. See [`../../sweep/README.md`](../../sweep/README.md) and
[`../../docs/canon.md`](../../docs/canon.md) rule 5.
